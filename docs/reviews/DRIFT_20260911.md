## UX / tracker failure on takeoff (fixed)

Observed: UI hitch for a few seconds when **Take off** fires; external track dies and never returns.

Cause:
1. `MediaRecorder.start` + flight state updates stall the main thread (>500 ms).
2. `external-camera.tsx` treated any rAF gap >500 ms as **permanent** `lost`.
3. `PatchTracker` had **no reacquisition** once `lost` was set.

Fix (this commit): remove gap→permanent-lost, coast through brief weak frames, reacquire with a wider search, defer recorder start, throttle React track updates, guard the rAF loop.
